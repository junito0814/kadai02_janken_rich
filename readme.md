# ①課題名
じゃんけんリッチアプリ

## ②課題内容（どんな作品か）
- このゲームはプレイヤーとCPUがじゃんけんで対戦し、先に20マス先のゴールに到達した方が勝ちとなる階段でするグリコゲームをモチーフにしたゲームです。
- グー・チョキ・パーのいずれかのボタンを押すと5秒のカウントダウンが始まります。
- カウントダウン中に手を変えることも可能で、0になった時点の手で勝負が決まります。
- 勝った手に応じて進めるマス数が異なり、グーで勝てば1マス、チョキで勝てば3マス、パーで勝てば5マス進みます。

## ⑤工夫した点・こだわった点
- じゃんけんの前にCPUが「今どの手を考えているか」をヒントとして表示する心理戦の要素を取り入れました。
- 勝つ手によって進めるマス数に差をつけることで、安全に1マスずつ進むか、リスクを取って一気に5マス進むかという戦略的な選択が生まれるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 階段でやるグリコのように上に上がっていくように進めるようにすることが難しかったです。
- 段数がうまく合わず、なぜか段数が増えてしまったりしたので、そこの調節が難しかったです。
